# WB32L003 VU Meter Firmware v2.0.0

## 发布日期
2025-07-01

## 版本说明
这是针对新的 WB32L003 引脚映射的重大更新版本。

## 主要更新
1. **全新引脚映射**
   - SPI 接口更改为 PC5(SCK)/PC6(MOSI)
   - 按键改为 PC13(电源键)/PC4(模式键)
   - LED 和其他控制引脚重新分配
   
2. **功能特性**
   - 实时音频 VU 表显示（1kHz 采样率）
   - STEREO/MONO 双模式支持
   - 电池电量监测与低电警告
   - 智能电源管理

3. **硬件兼容性**
   - MCU: WB32L003 (Cortex-M0+, 64KB Flash, 4KB SRAM)
   - 显示屏: 0.96" TFT ST7735S
   - 适配新的硬件设计

## 固件信息
- 文件大小: 64KB
- Flash 使用: ~50%
- RAM 使用: ~62.5%

## 烧录说明
使用 ST-Link 通过 SWD 接口烧录：
- SWDIO: PC7
- SWDCLK: PD1 (注意：实际硬件可能不同)
- VDD, GND

```bash
st-flash write firmware.bin 0x08000000
```

## 注意事项
1. 部分引脚（如 GPIOD）在实际硬件中可能不存在，已映射到其他端口
2. 请根据实际 PCB 设计确认最终引脚分配
3. UART 调试已配置为 PB6(TX)/PB7(RX)
