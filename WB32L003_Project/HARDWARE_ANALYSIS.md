# 硬件分析总结

## 已确认的硬件信息

### 1. TFT显示屏 (TFT096B039)
- **分辨率**: 80×160 RGB (注意：宽80，高160)
- **驱动IC**: ST7735S
- **接口**: 4-Wire SPI
- **供电**: VDD 2.5-3.3V, 背光 2.9-3.1V
- **背光电流**: 15-20mA

### 2. TFT引脚连接（已实现）
| TFT引脚 | MCU引脚 | 功能 |
|---------|---------|------|
| LEDA | PA1 | 背光控制(PWM) |
| GND | GND | 地 |
| RESET | PB2 | 复位信号 |
| RS(DC) | PB1 | 数据/命令选择 |
| SDA | PA7 | SPI数据(MOSI) |
| SCL | PA5 | SPI时钟 |
| VDD | 3.3V | 电源 |
| CS | PB0 | 片选 |

### 3. 其他已知引脚
- **BAT_ADC**: PA0 (电池电压检测)
- **KEY_PWR**: PC13 (电源键)

## 缺失的硬件信息

以下控制引脚在项目方案中提到，但没有具体GPIO分配：

| 信号名 | 功能描述 | 需要的IO类型 |
|--------|----------|--------------|
| CON_POW | 主电源控制 | 数字输出 |
| CON_LCD | LCD电源控制 | 数字输出 |
| MUTE | 音频静音控制 | 数字输出 |
| L_AD | 左声道音频检测 | ADC输入 |
| R_AD | 右声道音频检测 | ADC输入 |
| CHRG | 充电状态检测 | 数字输入 |
| V2 | 音频模式输出 | 数字输出 |
| Green | 绿色LED | 数字输出 |
| Red | 红色LED | 数字输出 |

## 固件改造方案

### 1. 修正显示分辨率
当前代码中分辨率是160×80，但实际应该是80×160（竖屏）。

### 2. 预留接口实现
为缺失的引脚创建软件接口，方便后续硬件确定后快速集成。

### 3. 可实现的功能
- ✅ 显示功能（已实现）
- ✅ 电池电压监测（已实现）
- ✅ 按键控制（已实现）
- ✅ STEREO/MONO切换（仅UI）
- ⚠️ 电源管理（部分实现）
- ❌ 音频电平检测（需要L_AD/R_AD）
