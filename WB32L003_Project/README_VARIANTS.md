# LCD显示变体说明

本项目支持多种LCD X轴偏移配置，以适配不同批次或厂商的0.96寸TFT显示屏。

## 变体列表

### 1. lcd_v1_no_offset
- **偏移量**：0像素
- **说明**：标准配置，无X轴偏移
- **适用**：理论标准屏幕
- **编译**：`make VARIANT=lcd_v1_no_offset`

### 2. lcd_v2_offset_24
- **偏移量**：+24像素
- **说明**：京东方demo默认偏移
- **适用**：京东方(BOE)标准批次
- **编译**：`make VARIANT=lcd_v2_offset_24`

### 3. lcd_v3_offset_26
- **偏移量**：+26像素
- **说明**：某些批次需要的偏移
- **适用**：特定批次屏幕
- **编译**：`make VARIANT=lcd_v3_offset_26`

### 4. lcd_v4_offset_32
- **偏移量**：+32像素
- **说明**：较大偏移配置
- **适用**：某些特殊批次
- **编译**：`make VARIANT=lcd_v4_offset_32`

## 如何选择正确的变体

1. **首次测试**：从 `lcd_v2_offset_24` 开始（京东方默认）
2. **显示偏左**：选择更大偏移的变体（v3或v4）
3. **显示偏右**：选择更小偏移的变体（v1）
4. **显示正常**：记录当前变体供后续使用

## 技术细节

所有变体的区别仅在于 `LCD_SetAddress()` 函数中的X轴偏移值：

```c
// v1: 无偏移
LCD_WriteData8(x1);      // 原始X坐标

// v2: +24像素偏移
LCD_WriteData8(x1 + 24); // X坐标加24

// v3: +26像素偏移
LCD_WriteData8(x1 + 26); // X坐标加26

// v4: +32像素偏移
LCD_WriteData8(x1 + 32); // X坐标加32
```

## 添加新变体

如需添加新的偏移值：

1. 复制 `Core/Src/lcd_v1_no_offset.c` 为新文件
2. 修改 `LCD_SetAddress()` 中的偏移值
3. 在Makefile中添加新的VARIANT选项
4. 更新本文档

## 常见问题

**Q: 屏幕完全不亮**
A: 检查引脚连接，确保使用GPIOC而非GPIOB

**Q: 显示内容被截断**
A: 可能是偏移过大，尝试较小偏移的变体

**Q: 显示闪烁或花屏**
A: 可能是SPI时序问题，与偏移无关
