# WB32L003 屏幕测试固件 v3.7

## 功能说明
这是一个专门用于测试 TFT LCD 显示屏的固件，实现了类似 STM32 demo 的 RGB 颜色循环显示。

## 测试步骤

1. **烧录固件**
   ```
   screen_test.hex - 推荐使用
   screen_test.bin - 二进制格式
   ```

2. **开机操作**
   - 按住电源按钮 2 秒以上
   - 松开后绿色 LED 应该亮起

3. **预期效果**
   屏幕将循环显示以下颜色（每种颜色持续 1 秒）：
   - 红色 (Red)
   - 绿色 (Green)  
   - 蓝色 (Blue)
   - 白色 (White)
   - 黑色 (Black)
   - 黄色 (Yellow)
   - 青色 (Cyan)
   - 洋红色 (Magenta)

## 技术细节

### 显示驱动更新
- 基于 STM32 demo 代码优化了 ST7735 初始化序列
- 使用软件 SPI 驱动（PB5=SCL, PB3=SDA）
- 背光控制：PB1=LOW 开启电源，PB2=HIGH 最高亮度

### 引脚映射
| 功能 | 引脚 | 说明 |
|------|------|------|
| LCD_RST | PB7 | 复位 |
| LCD_DC | PB6 | 数据/命令 |
| LCD_SCL | PB5 | SPI 时钟 |
| LCD_CS | PB4 | 片选 |
| LCD_SDA | PB3 | SPI 数据 |
| Backlight | PB1/PB2 | 背光控制 |

## 故障排除

1. **屏幕不亮**
   - 确认按钮按住时间足够长（≥2秒）
   - 检查绿色 LED 是否亮起
   - 确认 FPC 排线连接正常

2. **颜色异常**
   - 可能是显示模式设置问题
   - 检查 MADCTL 寄存器设置（0xC8）

3. **屏幕闪烁**
   - 可能是电源不稳定
   - 检查 USB 供电是否正常
