# LCD MVP 固件 v3.8 - 最小可用版本

## 🎯 这个版本的特点

基于京东方 0.96" IPS ST7735S 技术资料，实现了最小化的屏幕点亮测试。

### 关键改进：
1. **X轴偏移修正** - 添加了 24 像素偏移（京东方特有）
2. **VCOM 电压调整** - 使用 0x06（之前是 0x09）  
3. **简化的测试模式** - 只有基础颜色测试
4. **更完整的初始化** - 包含 Gamma 校正参数

## 📦 文件说明

- `lcd_mvp.hex` - 烧录文件（3KB，非常小）
- `lcd_mvp.bin` - 二进制格式

## 🚀 使用步骤

1. **烧录固件**
   - 使用 J-Link 或其他烧录工具
   - 烧录 `lcd_mvp.hex`

2. **开机操作**
   - 按住电源按钮 2 秒以上
   - 松开后绿色 LED 应该亮起

3. **预期效果**
   屏幕将循环显示：
   - 黑屏（初始状态）
   - 白屏（1秒）
   - 红屏（1秒）
   - 绿屏（1秒）
   - 蓝屏（1秒）
   - 四色块测试（2秒）
     - 左上：黄色
     - 右上：青色
     - 左下：洋红
     - 右下：白色

## 🔧 技术细节

### 引脚映射（WB32L003）
| 功能 | 引脚 | 说明 |
|------|------|------|
| LCD_RST | PB7 | 复位 |
| LCD_DC | PB6 | 数据/命令 |
| LCD_SCL | PB5 | SPI 时钟 |
| LCD_CS | PB4 | 片选 |
| LCD_SDA | PB3 | SPI 数据 |
| Backlight | PB1/PB2 | 背光控制 |

### 初始化特点
- 使用京东方推荐的初始化序列
- 地址偏移：X + 24 像素
- 显示模式：0x08（竖屏）
- 颜色格式：RGB565（16位）

## ❓ 故障排除

1. **屏幕完全不亮**
   - 检查电源是否正常（PC6 = LOW）
   - 确认背光是否开启（PB1 = LOW, PB2 = HIGH）

2. **显示偏移或错位**
   - 可能是 X 轴偏移问题
   - 尝试调整地址设置中的偏移值

3. **颜色异常**
   - 可能是 RGB/BGR 模式问题
   - 检查 MADCTL（0x36）寄存器设置

4. **屏幕闪烁**
   - 可能是帧率设置问题
   - 检查 B1-B3 寄存器的值
