# LCD Test Variants - 多种配置固件测试

## 🎯 目的

由于LCD无法点亮，我生成了多种配置变体的固件供逐一测试，以找出正确的初始化参数。

## 📦 X轴偏移变体 (v1-v4)

这组固件测试不同的X轴偏移值，其他参数保持相同：

| 文件名 | X轴偏移 | 说明 |
|--------|---------|------|
| `lcd_v1_no_offset.hex` | 0 | 标准模式，无偏移 |
| `lcd_v2_offset_24.hex` | 24 | 京东方推荐值 |
| `lcd_v3_offset_26.hex` | 26 | 某些屏幕需要此值 |
| `lcd_v4_offset_32.hex` | 32 | 备选偏移值 |

### 测试方法

1. 烧录固件后按住电源按钮2秒以上开机
2. 观察屏幕是否显示以下循环：
   - 白屏（1秒）
   - 红屏（1秒）
   - 绿屏（1秒）
   - 蓝屏（1秒）
   - 四色块测试（2秒）

### 可能的现象

- **完全黑屏**：可能是背光控制问题或电源问题
- **显示但错位**：X轴偏移值不正确，尝试其他版本
- **颜色异常**：可能是RGB/BGR模式问题
- **闪烁**：可能是帧率设置问题

### 共同参数

所有X轴偏移变体使用以下相同参数：
- VCOM电压：0x06（京东方推荐）
- 显示方向：0x08（RGB模式）
- 背光控制：开机后立即开启
- 初始化延迟：标准延迟（复位100ms，睡眠退出120ms）

## 🔧 技术细节

### 引脚映射
| 功能 | WB32L003引脚 |
|------|-------------|
| LCD_RST | PB7 |
| LCD_DC | PB6 |
| LCD_SCL | PB5 |
| LCD_CS | PB4 |
| LCD_SDA | PB3 |
| Backlight | PB1 |
| Power Latch | PC6 |

### 初始化序列
基于京东方 ST7735S 技术文档，包含完整的Gamma校正参数。
