# v3.9 电源诊断测试固件

## 问题背景
设备之前插入USB会发热，但刷入新固件后不再发热，疑似电源控制逻辑问题或程序未正常运行。

## 测试固件列表

### 1. pc6_low_test.hex (1307 字节)
- PC6 设置为 LOW 进行电源锁存
- 包含忙循环用于发热测试
- 基于之前的理解：PC6 LOW = 电源开启

### 2. pc6_high_test.hex (1241 字节)  
- PC6 设置为 HIGH 进行电源锁存
- 包含忙循环用于发热测试
- 测试假设：PC6 HIGH = 电源开启

### 3. no_gpio_test.hex (918 字节)
- 完全不控制任何GPIO引脚
- 纯忙循环测试
- 用于验证程序是否能正常启动和运行

## 测试方法
1. 分别烧录三个固件
2. 插入USB供电
3. 按下电源按钮
4. 观察30-60秒是否有发热现象

## 预期结果
- 如果任何一个版本发热 → 程序能运行，需找到正确的电源控制逻辑
- 如果都不发热 → 可能是程序启动问题或其他硬件问题

- ✅ pc6_high_test.hex - 无发热
