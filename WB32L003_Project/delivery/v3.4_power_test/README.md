# WB32L003 Power Test Package v3.4

## 文件说明

### 1. `minimal_pc6_test.hex` - 极简测试固件
- 只做一件事：保持 PC6 LOW 并闪烁红色 LED
- 如果 LED 闪烁，说明 MCU 在运行但电源/屏幕有问题
- 使用直接寄存器操作，避免 HAL 库干扰

### 2. `o3_debug_analysis.md` - 给 o3 的综合分析文档
- 包含所有版本历史和结果
- 晶体管逻辑分析总结
- 可能的问题原因分析
- 关键代码片段

### 3. `DEBUG_GUIDE.md` - 系统调试指南
- 分步骤的调试流程
- 硬件测量点
- 常见问题检查清单

### 4. `power_test_combinations.txt` - 电源控制组合表
- 所有 16 种可能的引脚组合
- 标注了理论上应该工作的组合

## 使用方法

1. 先烧录 `minimal_pc6_test.hex`
2. 观察红色 LED 是否闪烁
3. 如果 LED 闪烁但屏幕不亮，说明电源控制有问题
4. 如果 LED 也不闪烁，可能是 MCU 没有运行

## 给 o3 的问题

请参考 `o3_debug_analysis.md` 文档，主要问题：
- 为什么正确的晶体管逻辑仍然无法开机？
- 是否有遗漏的硬件初始化步骤？
- PB0 按钮在电源控制中的角色？
