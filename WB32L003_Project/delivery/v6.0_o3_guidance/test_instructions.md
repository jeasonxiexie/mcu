# LCD 渐进式测试固件说明

基于 o3 的详细硬件分析，创建了 3 个渐进式测试固件。

## 关键硬件发现：
- **LCD 引脚全部在 GPIOB**（PB3-PB7）
- **屏幕分辨率是 128x160**（不是 80x160）
- **LED 红灯确实可控**（PB0，低电平点亮）
- **背光有两路控制**：
  - PB1 = 高亮（低电平点亮）
  - PB2 = 低亮（高电平点亮）

## 测试固件：

### 1. test_v1_backlight_only.hex
**目的**：只测试背光是否能点亮

**预期行为**：
- LED 慢闪（0.5秒亮/灭）表示程序运行
- 背光应该以低亮度点亮（PB2 = HIGH）
- 每 5 次闪烁后，切换到高亮度 2 秒

**如果成功**：您应该看到屏幕背光亮起

### 2. test_v2_backlight_reset.hex
**目的**：测试背光 + LCD 复位序列

**预期行为**：
- 开始：LED 闪 1 次
- LCD 复位后：LED 闪 2 次
- 高亮度激活：LED 闪 3 次
- 主循环：背光在高/低亮度间切换
  - 低亮度时：LED 慢闪（1秒）
  - 高亮度时：LED 快闪（0.2秒）

**如果成功**：背光能正常切换亮度

### 3. test_v3_o3_init.hex
**目的**：完整的 LCD 初始化 + 显示测试

**预期行为**：
- 开始：LED 闪 1 次
- 初始化完成：LED 闪 2 次
- 填充红色完成：LED 闪 3 次
- 主循环：每 2 秒切换颜色
  - 红 → 绿 → 蓝 → 黄 → 紫 → 青 → 白 → 黑
  - 每次切换颜色时 LED 快闪 1 次

**如果成功**：屏幕显示不同颜色

## 测试步骤：

1. **烧录 test_v1**
   - 插入 USB
   - 按电源键
   - 观察背光是否亮起

2. **如果 v1 成功，测试 v2**
   - 观察背光亮度是否能切换

3. **如果 v2 成功，测试 v3**
   - 观察屏幕是否显示颜色

## 故障排查：

- **LED 不闪**：程序没有运行，检查电源
- **LED 闪但背光不亮**：背光电路问题
- **背光亮但无显示**：LCD 初始化或连接问题

## 重要提示：
- 测试时请在较暗环境观察，背光可能较弱
- 如果看到 LED 闪烁模式，记录下来有助于定位问题
