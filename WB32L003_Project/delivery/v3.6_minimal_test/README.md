# 最小电源测试固件 v3.6

## 🎯 测试目的

验证板子能持续供电 & LED 可见

## 💡 预期效果

如果固件正常工作，你应该看到：
- **红绿 LED 交替闪烁**（每 500ms 切换）
- PC1 绿灯 → PC0 红灯 → 循环

## 🔧 实现细节

1. **早期电源锁存**（150ms 内）
   - PC6 = LOW（主电源 ON）
   - PA3 = LOW（LCD 电源 ON）
   - PB1 = LOW（背光供电 ON）

2. **LED 控制**（共阳极）
   - PC0 = LOW → 红灯亮
   - PC1 = LOW → 绿灯亮

3. **无 HAL 依赖**
   - 直接寄存器操作
   - 最小化代码路径

## 📋 测试步骤

1. 烧录 `minimal_power_test.hex`
2. **按住电源按钮 2 秒以上**
3. 松开按钮
4. 观察 LED 是否闪烁

## ❓ 如果没有反应

### A. LED 不闪
- 固件没有运行
- 电源没有锁存成功
- LED 没有焊接

### B. 设备立即关机
- PC6 控制逻辑可能相反
- 按钮时间不够长

### C. 测量建议
- 3V3 电压是否稳定？
- PC6 引脚电压？
- NRST 是否反复复位？

## 🚀 下一步

如果 LED 能闪烁，说明：
1. ✅ 电源锁存成功
2. ✅ MCU 正常运行
3. ✅ 基本硬件正常

然后可以继续调试 LCD 和其他功能。
