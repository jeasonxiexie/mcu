# WB32L003 耳放固件 v3.6.0

## 🎯 这个版本解决了什么？

1. **电源无法锁存** → 早期电源锁存机制
2. **LED 不亮** → 修正为 PC0/PC1
3. **关机逻辑错误** → 正确的关机序列
4. **MODE 键无响应** → 修正为 PD3

## 📦 文件说明

- `firmware_v3.6.0.hex` - 主固件（完整功能）
- `firmware_v3.6.0.bin` - 二进制格式
- `../v3.6_minimal_test/minimal_power_test.hex` - 最小测试固件（LED 闪烁）

## 🚀 快速开始

### 步骤 1：测试基本硬件
1. 烧录 `minimal_power_test.hex`
2. 按住电源按钮 2 秒
3. 应该看到红绿 LED 交替闪烁（每 500ms）

### 步骤 2：使用主固件
1. 烧录 `firmware_v3.6.0.hex`
2. 按住电源按钮 2 秒
3. 预期效果：
   - 绿色 LED 常亮（正常工作）
   - 屏幕显示 VU 表
   - 可以按 MODE 键切换立体声/单声道

## 🔌 引脚功能表

| 功能 | 引脚 | 说明 |
|------|------|------|
| 电源按钮 | PB0 | 按住 2 秒开机 |
| MODE 按钮 | PD3 | 切换 STEREO/MONO |
| 绿色 LED | PC1 | LOW=亮，正常工作指示 |
| 红色 LED | PC0 | LOW=亮，低电量警告 |
| 主电源 | PC6 | LOW=ON（内部控制） |
| LCD 电源 | PA3 | LOW=ON（内部控制） |

## ❓ 故障排除

### 设备不开机
- 确认按钮按住时间 ≥ 2 秒
- 检查 USB 供电是否正常
- 试试最小测试固件

### LED 不亮
- 确认 LED 已焊接在 PC0/PC1
- 测试固件应该让 LED 闪烁

### 屏幕不亮
- 检查 FPC 排线连接
- 确认背光引脚 PB1/PB2

### MODE 键无响应
- MODE 键应该连接到 PD3
- 不是 PB6！
