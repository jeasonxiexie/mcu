# Firmware v3.6.0 - o3 Complete Fix

## 发布日期：2025-08-01

## 🎯 核心改进

基于 o3 的详细对比分析，修复了所有硬件控制逻辑问题。

## 🔧 主要修改

### 1. 早期电源锁存（关键！）
- 在 Reset_Handler 中立即调用 `Early_PowerLatch()`
- 确保在 150ms 窗口内设置 PC6 = LOW
- 使用直接寄存器操作，避免 HAL 延迟

### 2. 电源控制逻辑修正
- **开机**：PC6=LOW, PA3=LOW（与项目描述相反，但硬件需要）
- **关机**：PA4=LOW → 延时 → PC6=HIGH, PA3=HIGH
- **背光**：PB1 必须保持 LOW，PB2 控制亮度

### 3. LED 控制修正
- 使用正确的引脚：PC0（红）、PC1（绿）
- 共阳极设计：LOW = 亮，HIGH = 灭
- 移除错误的 PA7/PD3 定义

### 4. MODE 按键修正
- MODE 键在 PD3（不是 PB6）
- 用于切换 STEREO/MONO 模式

### 5. 关机序列优化
```c
// 新的关机序列
1. PA4 = LOW   // 静音
2. 延时 200ms  // 可选：显示关机画面
3. PC6 = HIGH  // 切断主电源
4. PA3 = HIGH  // 切断 LCD 电源
```

## 📋 测试步骤

1. **先试最小测试固件**
   - 烧录 `minimal_power_test.hex`
   - 应该看到红绿 LED 交替闪烁

2. **再试主固件**
   - 烧录 `firmware_v3.6.0.hex`
   - 按住电源按钮 **2 秒以上**
   - 松开后应该：
     - 绿色 LED 亮起
     - 屏幕显示开机画面
     - 音频解除静音

## ⚠️ 注意事项

1. **必须按住按钮 2 秒** - 给 MCU 足够时间锁存电源
2. **项目描述与实际相反** - 硬件需要 LOW 电平开机
3. **LED 在 PC0/PC1** - 不是 PA7/PD3

## 🔍 如果还是不行

1. 检查是否有 LED 闪烁（最小测试固件）
2. 测量 3V3 电压是否稳定
3. 确认按钮按压时间足够长
4. 检查 NRST 是否反复复位
