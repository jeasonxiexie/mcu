# Firmware v3.5.0 - Early Power Latch Fix

## 🎯 核心问题（o3 发现）

**按钮只能维持 150ms 电源！** 如果 MCU 不能在这个时间窗口内把 PC6 拉低，就会掉电死循环。

## 🔧 修复方案

根据 o3 的分析，在 `Reset_Handler` 最早期调用 `Early_PowerLatch()` 函数：

```c
void Early_PowerLatch(void) {
    // 1. 开启 GPIOC 时钟
    RCC_AHBENR |= RCC_AHBENR_GPIOCEN;
    
    // 2. 最小延时确保时钟稳定
    __asm__("nop");
    
    // 3. PC6 设为输出
    GPIOC_MODER &= ~(3UL << (6 * 2));
    GPIOC_MODER |= (1UL << (6 * 2));
    
    // 4. 立即拉低 PC6 - 锁住电源！
    GPIOC_BRR = (1UL << 6);
}
```

## 📋 测试步骤

### ① 确认主电源能锁存
1. 烧录 `firmware_v3.5.0.hex`
2. **按住 PB0 按钮 2 秒**，然后松开
3. 测量 3V3 是否稳定存在

### ② 观察屏幕背光
如果电源锁存成功，应该能看到：
- 屏幕背光亮起（PA3=LOW, PB1=LOW）
- 背光为高亮度（PB2=HIGH）

### ③ 如果还是不行
- 检查是否进入了 ISP 模式
- 测量各关键点电压
- 确认按钮按压时间足够长

## 🔌 关键信号状态

| 信号 | 引脚 | 开启状态 | 关闭状态 | 作用 |
|------|------|----------|----------|------|
| 主电源 | PC6 | LOW | HIGH | 控制 P-MOS Q5 |
| LCD电源 | PA3 | LOW | HIGH | 控制 PNP Q7 |
| 背光电源 | PB1 | LOW | HIGH | 控制 PNP Q7 |
| 背光亮度 | PB2 | HIGH=亮 | LOW=暗 | 亮度控制 |

## ⚡ 关键改进

1. **超早期电源锁存** - 在任何系统初始化之前
2. **直接寄存器操作** - 避免 HAL 延迟
3. **最小化启动时间** - 确保在 150ms 窗口内
