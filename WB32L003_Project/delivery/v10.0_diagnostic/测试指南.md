# v10.0 LCD诊断测试固件 - 测试指南

基于 o3pro 的系统排查方案

## 测试程序特性

1. **LED指示**：使用 PB0 作为运行指示灯
   - 启动时快速闪烁3次
   - 运行中每秒闪烁一次

2. **慢速SPI**：每个时钟周期有1ms延时，便于逻辑分析仪捕获

3. **测试模式**：持续发送0xAA、0x55等特征模式

## 测试步骤

### 步骤1：检查LCD电源（PA3）

使用万用表测量：
- **PA3 对 GND**：应该是 0V（LCD电源开启）
  - 如果是 3.3V，说明LCD没有供电
- **LCD模块 VCC 对 GND**：应该是 3.0-3.3V
- **背光 LEDA 对 LEDK**：应该 ≥2.8V

### 步骤2：检查复位脉冲（PC3）

使用示波器或逻辑分析仪：
- 观察 PC3 引脚
- 应该看到：高电平 → 50ms低电平 → 高电平
- 如果一直高或一直低，复位有问题

### 步骤3：检查SPI信号

连接逻辑分析仪到以下引脚：

| MCU引脚 | 信号 | 预期波形 |
|---------|------|----------|
| PC5 | SCL | 时钟脉冲（慢速） |
| PC6 | MOSI | 数据（0xAA/0x55模式） |
| PC0 | CS | 命令期间为低 |
| PC1 | DC | 命令时低，数据时高 |

### 步骤4：判断排线脚序

如果PC5/PC6有信号但屏幕不亮，检查FPC排线：
- 测量FPC第3、4脚
- 确认哪个是时钟信号
- 如果与代码相反，需要交换SCL/SDA定义

### 步骤5：PC6电源冲突检测

用示波器监测3.3V电源：
- 如果在SPI通信时电压掉到0再恢复
- 说明PC6（MOSI）与电源锁存冲突
- 需要硬件修改

## 快速诊断流程

1. **PB0 LED闪烁？**
   - 是 → MCU运行正常，继续步骤2
   - 否 → 检查烧录是否成功

2. **PA3 = 0V？**
   - 是 → LCD已供电，继续步骤3
   - 否 → LCD电源控制有问题

3. **PC3有复位脉冲？**
   - 是 → 复位正常，继续步骤4
   - 否 → 复位信号有问题

4. **PC5/PC6有SPI信号？**
   - 是 → 检查排线脚序
   - 否 → 引脚映射仍有问题

5. **背光亮但无显示？**
   - 可能是ST7789而非ST7735S
   - 尝试不同的初始化序列

## 预期结果

如果一切正常，LCD应该显示红色填充屏幕。
