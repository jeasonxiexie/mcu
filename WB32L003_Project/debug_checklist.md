# 调试检查清单

## 1. 烧录验证
- [ ] hex 文件是否成功烧录？
- [ ] 烧录工具显示的芯片 ID 是否正确？
- [ ] 烧录后是否验证成功？

## 2. 硬件检查
- [ ] USB 供电是否正常？（测量 VBUS = 5V）
- [ ] 按钮按下时，是否有任何反应？
- [ ] 板上是否有任何 LED 或指示灯？
- [ ] 是否听到任何声音（蜂鸣器等）？

## 3. 关键测量（如果有万用表）
按住按钮时测量：
- [ ] 3V3 电压是否出现？
- [ ] PC6 引脚电压？
- [ ] 按钮松开后 3V3 是否立即消失？

## 4. 可能的问题

### A. 固件根本没运行
- 芯片型号不对？
- Flash 地址不对？（我们已经改为 0x00000000）
- 启动模式引脚状态？

### B. 时钟问题
- 外部晶振没有？
- PLL 配置错误导致死机？

### C. 硬件问题
- 电源芯片损坏？
- 按钮接触不良？
- 板子版本不同？

## 5. 最简单的测试

创建一个什么都不做的固件，只是死循环：

```c
void Early_PowerLatch(void) {
    // 什么都不做
}

int main(void) {
    while(1) {
        __asm__("nop");
    }
}
```

如果这个也不能让设备保持开机，说明：
1. 固件没有运行
2. 或者 PC6 不是电源控制引脚

## 6. 问 o3 的问题

1. **确认 PC6 就是控制主电源的引脚吗？**
2. **按钮按下时，P-MOS 能维持多久？真的只有 150ms？**
3. **是否需要 BOOT 引脚的特殊配置？**
4. **WB32L003 的启动时间是多少？**

## 7. 另一种可能

项目描述提到 "闭合开关Power_SW下拉为开机"，这听起来像是：
- 不是瞬时按钮，而是拨动开关？
- 一直保持闭合状态？

如果是这样，那问题可能完全不同。
