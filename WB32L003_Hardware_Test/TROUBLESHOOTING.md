# 故障排查指南

## 快速诊断流程图

```
MCU上电
  │
  ├─> PC6是3.3V吗？
  │     │
  │     ├─> 否 → 电源锁存失败 → 检查早期初始化代码
  │     │
  │     └─> 是 → 继续
  │
  ├─> 串口有输出吗？(PA9, 115200)
  │     │
  │     ├─> 是 → MCU运行正常 → 检查LED配置
  │     │
  │     └─> 否 → MCU可能未运行或串口配置错误
  │
  └─> LED引脚电压变化吗？
        │
        ├─> 是 → LED极性可能相反 → 修改LED_ACTIVE_LOW
        │
        └─> 否 → 引脚配置错误 → 检查实际连接
```

## 详细排查步骤

### ❌ 问题1：MCU完全没反应

**症状：**
- 没有LED闪烁
- 没有串口输出
- PC6电压为0V

**可能原因：**
1. 电源锁存失败（最常见）
2. MCU未正确烧录
3. 电源问题

**解决方法：**
```c
// 检查simple_test.c中的电源锁存配置
#define POWER_LATCH_GPIO    'C'      // 确认是PC6
#define POWER_LATCH_PIN     6         
```

**测试方法：**
- 用示波器查看PC6，应该在上电后立即变高
- 如果PC6一直是低，说明代码没有执行到锁存部分

---

### ❌ 问题2：LED不亮但MCU在运行

**症状：**
- 串口有输出
- PC6是3.3V
- LED不亮

**可能原因：**
1. LED引脚配置错误
2. LED极性相反
3. LED硬件问题

**解决方法：**

1. **确认实际LED引脚**
   ```c
   // 修改为实际引脚
   #define LED1_GPIO           'B'      // 比如改为PB0
   #define LED1_PIN            0         
   ```

2. **检查LED极性**
   ```c
   // 尝试改变这个值
   #define LED_ACTIVE_LOW      0         // 改为高电平亮
   ```

**测试方法：**
- 用万用表测量LED引脚电压
- 应该看到0V和3.3V切换
- 如果电压正常但LED不亮，是极性问题

---

### ❌ 问题3：串口无输出

**症状：**
- LED正常闪烁
- 串口没有任何输出

**可能原因：**
1. 串口连接错误
2. 波特率不匹配
3. TX引脚配置错误

**解决方法：**
```c
// 确认串口配置
#define ENABLE_UART         1         // 确保启用
#define UART_TX_GPIO        'A'      // PA9
#define UART_TX_PIN         9         
```

**连接方法：**
```
MCU PA9 (TX) ----> USB转串口 RX
MCU GND      ----> USB转串口 GND
```

**串口设置：**
- 波特率：115200
- 数据位：8
- 停止位：1
- 校验：无

---

### ❌ 问题4：LED快速闪烁（错误状态）

**症状：**
- LED以100ms间隔快速闪烁
- 不是正常的500ms交替闪烁

**可能原因：**
- 程序进入了HardFault_Handler
- MCU遇到了硬件错误

**解决方法：**
- 检查电源电压是否稳定
- 确认晶振工作正常
- 重新烧录程序

---

## 测量点检查清单

使用万用表或示波器检查以下测量点：

| 测量点 | 预期值 | 说明 |
|--------|--------|------|
| PC6 | 3.3V | 电源锁存信号 |
| PA9 | 有脉冲 | UART TX信号 |
| LED1引脚 | 0V⟷3.3V | 每500ms切换 |
| LED2引脚 | 0V⟷3.3V | 每500ms切换 |
| VDD | 3.3V | 电源电压 |
| NRST | 3.3V | 复位引脚（高电平） |

## 常见配置错误

### 1. LED引脚错误
```c
// 错误：假设LED在PC0/PC1
#define LED1_GPIO 'C'
#define LED1_PIN  0

// 正确：实际LED在PB0/PB1
#define LED1_GPIO 'B'
#define LED1_PIN  0
```

### 2. LED极性错误
```c
// 错误：假设低电平亮
#define LED_ACTIVE_LOW 1

// 正确：实际高电平亮
#define LED_ACTIVE_LOW 0
```

### 3. 电源锁存引脚错误
```c
// 错误：错误的锁存引脚
#define POWER_LATCH_GPIO 'B'
#define POWER_LATCH_PIN  7

// 正确：根据RTF文档应该是PC6
#define POWER_LATCH_GPIO 'C'
#define POWER_LATCH_PIN  6
```

## 调试技巧

### 1. 最简化测试
如果怀疑是代码问题，可以写一个更简单的测试：
```c
int main(void) {
    // 只做电源锁存
    RCC->AHBENR |= (1UL << 19);  // GPIOC时钟
    GPIOC->MODER |= (1UL << 12); // PC6输出
    GPIOC->BSRR = (1UL << 6);    // PC6高电平
    
    while(1); // 死循环
}
```
如果这样都掉电，说明硬件有问题。

### 2. 用LED调试
在代码关键位置加入LED闪烁，定位程序运行到哪里：
```c
// 闪1次 - 到达点1
for(int i=0; i<1; i++) { /*闪烁代码*/ }

// 闪2次 - 到达点2  
for(int i=0; i<2; i++) { /*闪烁代码*/ }
```

### 3. 检查时钟配置
如果延时不准确，可能是时钟配置问题。默认使用内部HSI 8MHz，PLL倍频到32MHz。
