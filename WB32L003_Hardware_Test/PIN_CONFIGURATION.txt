WB32L003 引脚配置说明
========================================
日期：2024年
版本：v1.0
基于：RTF硬件规格文档
========================================

【当前配置】- 基于RTF文档
========================================

1. 电源控制引脚
----------------
PC6 - CON_POW_CPU    [关键！电源锁存，必须HIGH]
PC5 - CON_POW_RF     [5V升压控制]
PA3 - CON_POW_LCD    [LCD电源控制]

注意：PC6必须在上电150ms内拉高，否则会掉电！

2. LED指示灯（需要确认）
------------------------
PC0 - LED1 (红色?)   [假设低电平点亮]
PC1 - LED2 (绿色?)   [假设低电平点亮]

⚠️ 警告：LED引脚可能不正确，需要硬件确认！

3. 串口调试
-----------
PA9 - USART1_TX      [调试输出，115200 baud]
PA8 - USART1_RX      [未使用]

4. LCD接口（v2版本）
--------------------
PB7 - LCD_RESET      [LCD复位]
PB6 - LCD_RS         [数据/命令选择]
PB5 - LCD_SCL        [SPI时钟]
PB4 - LCD_CS         [片选]
PB3 - LCD_SDA        [SPI数据]
PB2 - LCD背光?       [待确认]
PB1 - LCD背光?       [待确认]

5. 用户按键
-----------
PB0 - SW_POW         [电源开关]

6. 音频控制
-----------
PA4 - CON_MUTE       [静音控制]

========================================
【如何修改LED引脚】
========================================

1. 打开 source/simple_test.c

2. 找到配置区域（约第20行）：

   // LED配置
   #define LED1_GPIO           'C'      // 改这里！
   #define LED1_PIN            0         // 改这里！
   #define LED2_GPIO           'C'      // 改这里！
   #define LED2_PIN            1         // 改这里！

3. 根据实际硬件修改，例如：
   - 如果LED在PB0和PB1：
     #define LED1_GPIO           'B'
     #define LED1_PIN            0
     #define LED2_GPIO           'B'
     #define LED2_PIN            1

   - 如果LED在PA5和PA6：
     #define LED1_GPIO           'A'
     #define LED1_PIN            5
     #define LED2_GPIO           'A'
     #define LED2_PIN            6

4. 修改LED极性（如果需要）：
   #define LED_ACTIVE_LOW      1   // 1=低电平亮, 0=高电平亮

5. 重新编译（双击build.bat）

========================================
【GPIO引脚范围】
========================================

GPIOA: PA0-PA15 (16个引脚)
GPIOB: PB0-PB15 (16个引脚)
GPIOC: PC0-PC15 (16个引脚)
GPIOD: PD0-PD3  (仅4个引脚，WB32L003可能没有)

注：WB32L003是48脚封装，不是所有GPIO都引出

========================================
【测试建议】
========================================

如果不确定LED在哪个引脚，可以：

1. 用万用表测量各个GPIO引脚
2. 看哪个引脚有0V和3.3V切换
3. 那就是LED控制引脚

或者逐个尝试常见的LED引脚：
- PC0/PC1（当前假设）
- PB0/PB1（常见选择）
- PA0/PA1（另一种可能）
- PC13（有些板子用这个）

========================================
【重要提醒】
========================================

1. PC6必须正确！这是电源锁存，错了MCU会掉电
2. LED引脚错了只是看不到闪烁，不影响MCU运行
3. 最好的验证方法是看串口输出（PA9）
4. 如果什么都没反应，先检查PC6是否3.3V
