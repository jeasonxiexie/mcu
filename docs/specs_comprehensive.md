## 2. 耳放项目完整方案

### 2.1 系统概述
- **项目名称**：耳放项目方案
- **核心 MCU**：WB32L003 QFN32封装（Cortex-M0+, 64 KB Flash, 8 KB RAM）
- **显示屏**：0.96" TFT (TFT096B039)
- **用户接口**：1个MODE按键 + 1个电源开关(Power_SW)
- **供电**：3.7V锂电池，MCU供电DC3.3V

### 2.2 功能详细说明

#### 2.2.1 电源管理序列
**开机流程**：
1. 闭合Power_SW开关（下拉）触发开机
2. CON_POW和CON_LCD引脚输出高电平
3. 显示开机画面
4. 开机完成后MUTE输出高电平（解除静音）

**关机流程**：
1. 断开Power_SW开关触发关机
2. MUTE输出低电平（静音）
3. 显示关机画面
4. CON_POW和CON_LCD引脚输出高电平
5. 关机完成，MCU进入低功耗状态

#### 2.2.2 显示屏控制
- 开机后显示屏高亮
- 无操作20秒后背光降低一级
- 任何操作恢复高亮

#### 2.2.3 电池电压检测
**硬件设计**：
- BATT-Voltage检测点
- 分压电路：R1=47K（接电池正极），R2=47K（下拉）
- 分压比：1/2

**电量指示逻辑**：
- 电压 > 3.7V：显示满格（4格电量）
- 电压 < 3.0V：电池图标变红色，LED闪烁（亮2秒，灭0.5秒）
- 电压 ≥ 3.0V：Green输出低电平（绿灯亮），Red输出高电平（红灯灭）
- 电压 < 3.0V：Green输出高电平（绿灯灭），Red输出低电平（红灯闪烁）
- 电压 < 2.8V（红灯亮起10分钟后）：自动关机

**自动关机序列**：
1. MUTE输出低电平
2. 显示关机画面
3. CON_POW和CON_LCD引脚输出高电平
4. MCU进入低功耗状态

#### 2.2.4 充电功能
**充电检测**：
- CHRG引脚低电平时进入充电状态
- 充电分压电路：R3连接充电和P1.3，R4下拉（R3=47K，R4=47K，分压比1/2）

**充电显示**：
- 充电电压 < 4.2V：电池电量指示从第一格渐亮到第四格循环（0.5秒亮一格）
- CHRG高电平时退出充电状态

#### 2.2.5 音频模式控制
**MODE按键功能**：
- 短按切换STEREO/MONO模式
- 显示屏对应显示当前模式
- STEREO模式：V2输出低电平
- MONO模式：V2输出高电平
- 关机后保存选择的模式状态
- 开机恢复断电时的模式状态

#### 2.2.6 音频电平检测
**检测通道**：
- L_AD：左声道音频电平检测
- R_AD：右声道音频电平检测

**显示模式**：
- STEREO模式：左、右声道独立检测，独立显示
- MONO模式：使用其中一个通道检测，统一显示

### 2.3 控制信号汇总

| 信号名 | 方向 | 功能 | 电平定义 |
| ------ | ---- | ---- | -------- |
| CON_POW | 输出 | 主电源控制 | 高电平有效 |
| CON_LCD | 输出 | LCD电源控制 | 高电平有效 |
| MUTE | 输出 | 音频静音控制 | 高=解除静音，低=静音 |
| L_AD | 输入 | 左声道音频检测 | 模拟输入 |
| R_AD | 输入 | 右声道音频检测 | 模拟输入 |
| CHRG | 输入 | 充电状态检测 | 低=充电中 |
| V2 | 输出 | 音频模式控制 | 低=STEREO，高=MONO |
| Green | 输出 | 绿色LED控制 | 低=亮，高=灭 |
| Red | 输出 | 红色LED控制 | 低=亮，高=灭 |
| BATT-Voltage | 输入 | 电池电压检测 | 模拟输入（1/2分压） |
| Power_SW | 输入 | 电源开关 | 闭合=开机，断开=关机 |
| MODE | 输入 | 模式切换按键 | 按下触发 |

## 3. 关键发现总结

### 3.1 缺失的GPIO分配
经过对所有文档的详细分析，以下控制信号在规格中明确定义但尚未分配具体GPIO：

1. **CON_POW** - 主电源控制输出
2. **CON_LCD** - LCD电源控制输出  
3. **MUTE** - 音频静音控制输出
4. **L_AD** - 左声道音频ADC输入
5. **R_AD** - 右声道音频ADC输入
6. **CHRG** - 充电检测输入
7. **V2** - 音频模式控制输出
8. **Green** - 绿色LED控制输出
9. **Red** - 红色LED控制输出

### 3.2 建议的GPIO分配方案
基于WB32L003的引脚资源，建议分配如下：
- CON_POW: PA3 或 PA4
- CON_LCD: PA6 或 PB3
- MUTE: PB4 或 PB5
- CHRG: PA8 (支持中断)
- L_AD: PA4 (ADC_CHANNEL_4)
- R_AD: PA6 (ADC_CHANNEL_6) 
- V2: PB6
- Green: PB7
- Red: PA9
