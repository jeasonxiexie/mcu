# Version 1 参考文档

本目录包含V1版本（GPIOC标准原理图版本）的参考文档。

## 📄 文档列表

### 1. 主板原理图.pdf
- **说明**: WB32L003 MCU主板完整原理图
- **内容**: 
  - MCU引脚连接
  - 电源电路
  - 按钮接口（PB0电源键，PD3模式键）
  - 音频电路
  - 充电管理

### 2. 0.96寸插接式原理图.pdf  
- **说明**: 0.96寸 IPS LCD模块（ST7735S）原理图
- **内容**:
  - LCD接口定义
  - ST7735S控制器连接
  - 背光电路
  - 8pin插接口定义
