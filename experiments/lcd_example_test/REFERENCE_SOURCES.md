# 引脚定义的来源说明

调试LCD不亮的时候发现了引脚定义问题，这里记录一下两套引脚定义是从哪来的。

## 第一套：来自主板原理图 (GPIOC)

我从主板原理图.pdf上看到的引脚定义：
- PC0 - 片选
- PC1 - DC(数据/命令)
- PC3 - 复位
- PC5 - 时钟
- PC6 - 数据

按这个写的代码测试。

## 第二套：来自RTF文档 (GPIOB)

后来找到一个文档 WB32L003 耳放固件.rtf，里面写着：
```
LCD SPI接口
    LCD_RST -> PB7
    LCD_RS  -> PB6
    LCD_SCL -> PB5
    LCD_CS  -> PB4
    LCD_SDA -> PB3
```

看这个文档，实际板子把LCD改到GPIOB了，所以做了第二个版本。

## 两个版本

因为有两套不同的引脚定义，所以整理了两个版本：
- GPIOC版本 - 按原理图的引脚
- GPIOB版本 - 按RTF文档的引脚
