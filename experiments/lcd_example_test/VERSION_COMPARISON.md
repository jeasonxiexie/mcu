# 两个版本的差异

因为发现原理图和实际板子的引脚不一样，所以整理了两个版本。

## 版本说明

V1 - 按原理图的 (GPIOC)  
目录：v1_gpioc_standard_schematic/

V2 - 按RTF文档的 (GPIOB)  
目录：v2_gpiob_actual_hardware/

## 引脚差异

| LCD信号 | 原理图(V1) | RTF文档(V2) |
|---------|------------|------------|
| SCL | PC5 | PB5 |
| SDA | PC6 | PB3 |
| CS | PC0 | PB4 |
| DC/RS | PC1 | PB6 |
| RST | PC3 | PB7 |

背光都是用PB1/PB2，但V2的文档里说是通过Q7晶体管控制。

## 代码文件

两个版本都是完全独立的，各自包含了所有需要的HAL库和启动文件。
主要差别就是lcd_init.h里的引脚定义不同。

## 编译方法

每个版本都有自己的Makefile，可以单独编译。
或者用根目录的build_all脚本一次编译两个。

生成的固件大小都差不多，6KB左右。

注意：引脚不对的话LCD不亮，现在整理了两个版本来测试。
