## 🔌 引脚映射来源

V2版本基于实际PCB设计，使用GPIOB作为LCD接口：
- LCD数据线连接到 PB3, PB4, PB5, PB6, PB7
- 背光控制使用 PB1, PB2
- 这是最终产品的实际硬件连接
