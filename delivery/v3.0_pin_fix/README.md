# 引脚修正版本 v3.0

## 重要发现

根据原理图分析，发现以下关键问题：

1. **MCU 不控制主电源**
   - CON_POW_CPU 信号不连接到 MCU
   - 主电源可能由外部硬件或物理开关控制
   - 需要硬件团队确认具体控制方式

2. **引脚分配错误**
   - 音频 ADC、LED 等多个引脚分配错误
   - 已根据原理图修正

## 修复内容

### 1. 引脚映射修正
| 功能 | 错误引脚 | 正确引脚 |
|------|----------|----------|
| 左声道 ADC | PC1 | PC4 |
| 右声道 ADC | PC2 | PC3 |
| 绿色 LED | PB2 | PC1 |
| 红色 LED | PB0 | PC0 |

### 2. 电源控制修改
- 移除了无效的 MCU 电源控制代码
- 添加 LED 闪烁表示 MCU 已启动
- 等待外部电源就绪

### 3. 代码变更
```c
// hardware_control.c - 电源控制函数现在为空
void HW_SetMainPower(bool enable) {
    // MCU 不控制主电源
}

// main.c - 启动时闪烁 LED
HW_SetGreenLED(true);
HAL_Delay(200);
HW_SetGreenLED(false);
```

## 测试步骤

1. 烧录 firmware_pin_fixed.hex
2. 确保外部电源已开启（物理开关或其他控制）
3. 观察绿色 LED 是否闪烁（表示 MCU 运行）
4. 如果屏幕仍不亮，需要：
   - 确认外部电源控制方式
   - 检查 SPI 连接是否正常
