需要问洪哥的关键问题
====================

1. TFT 屏幕具体型号
-------------------
- 是 0.96 寸 ST7735 驱动的屏幕吗？
- 还是其他型号（如 SSD1306、ILI9163）？
- 屏幕分辨率是 80x160 还是其他？

2. 硬件连接确认
--------------
请确认以下连接是否正确：
- TFT_SCK  → PC5
- TFT_MOSI → PC6
- TFT_CS   → PC0
- TFT_DC   → PA3
- TFT_RST  → PD3
- TFT_BL   → PA1（背光）
- TFT_VCC  → 3.3V
- TFT_GND  → GND

3. 供电问题
----------
- WB-Link PRO 的 3.3V 供电是否足够？
- 是否需要额外接 USB-C 提供 5V 给运放和背光？
- 背光控制是否需要特殊的驱动电路？

4. 测试步骤
----------
请帮忙测试：
1) 用万用表测量 TFT VCC 引脚是否有 3.3V
2) 测量 PA1（背光）引脚电压
3) 按 MODE 键（金色按钮）时，PD0 是否有变化？

5. 原理图
--------
如果有原理图，特别是：
- TFT 连接部分
- 背光控制电路
- 电源管理部分

诊断建议
--------
根据 LED1 常亮，说明：
✓ MCU 已上电并运行固件
✓ Flash 烧录成功
✓ 3.3V 电源正常

可能的问题：
- TFT 型号不匹配（需要不同的初始化序列）
- 背光没有开启（最常见）
- SPI 连接问题
- 需要额外的 5V 供电

快速测试方法
-----------
1. 直接将 TFT_BL（PA1）接到 3.3V，看屏幕是否亮起
2. 如果亮起但没有显示，说明是 SPI 通信或初始化问题
3. 如果不亮，说明是背光电路问题
