TFT 屏幕不亮排查指南
====================

1. 硬件连接检查
--------------
请确认 0.96" TFT 屏幕连接正确：
- SCK  → PC5（SPI 时钟）
- MOSI → PC6（SPI 数据）
- CS   → PC0（片选）
- DC   → PA3（数据/命令）
- RST  → PD3（复位）
- BL   → PA1（背光）
- VCC  → 3.3V
- GND  → GND

2. 电源检查
----------
- 确认板子有 3.3V 供电
- 检查 TFT 屏幕的 VCC 和 GND 是否接好
- 测量屏幕 VCC 引脚电压是否为 3.3V

3. 按键测试
----------
金色按钮（MODE 键）功能：
- 短按：切换 STEREO/MONO 模式
- 如果屏幕正常工作，按键会切换显示模式

4. 可能的问题
------------
a) 屏幕型号不匹配
   - 代码针对 ST7735 驱动的 0.96" TFT
   - 如果是其他驱动芯片（如 SSD1306），需要修改驱动

b) 背光没有开启
   - 背光引脚（PA1）可能需要高电平才能点亮
   - 检查背光引脚是否有电压输出

c) SPI 通信问题
   - 检查 SPI 引脚焊接是否良好
   - 确认没有虚焊或短路

5. 调试建议
----------
1) 用万用表测量：
   - TFT VCC 引脚：应该是 3.3V
   - TFT BL 引脚：应该有 PWM 信号或高电平
   - RST 引脚：应该是高电平（不在复位状态）

2) 检查 LED 指示：
   - LED3 是否闪烁？（系统运行指示）
   - LED4 是否有反应？（音频输入指示）

3) 尝试按 MODE 键：
   - 即使屏幕不亮，MCU 可能在正常运行
   - 按键可能会触发其他 LED 变化

6. 紧急修复
----------
如果确认是背光问题，可以：
1) 直接将 BL 引脚接到 3.3V（常亮）
2) 或者修改代码强制开启背光

如果是驱动问题：
- 需要确认屏幕具体型号和驱动芯片
- 可能需要修改 st7735.c 中的初始化序列
